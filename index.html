GitHub Pages + Firebase 百人連線 5 分鐘極簡上線教學

為什麼選 Cloud Firestore 免費版？

Firebase Realtime Database 免費版有 100 人同時連線硬上限；本系統改用 Cloud Firestore（免費 Spark 方案），沒有 100 人連線限制，每天免費 50,000 次讀取與 20,000 次寫入，免綁信用卡即可穩撐 100～150 人早會！

步驟 0免費申請 GitHub 帳號（如已有帳號可略過，約 2 分鐘）

  1. 開啟 github.com/signup，輸入常用 Email、設定密碼並取一個英文使用者名稱（例如 health-morning-quiz，未來網址會是 https://使用者名稱.github.io/專案名/）。
  2. 完成防機器人小驗證後，到信箱收取 8 碼驗證碼並輸入，即可完成免費帳號申請。
  3. 個人化問卷頁面可直接捲到底部點 Skip personalization 略過，選擇 Free（免費方案） 進入主頁。

步驟 1免費建立 Firebase Cloud Firestore（約 2 分鐘）

  1. 用 Google 帳號登入 console.firebase.google.com → 點「新增專案」→ 輸入名稱（例如 health-coin-quiz）→ 關閉 Google Analytics → 建立專案。
  2. 左側選單點「建構 → Firestore Database」→ 點「建立資料庫」→ 選 asia-east1 (台灣) → 先選「以測試模式啟動」→ 建立。
  3. 在 Firestore「規則 (Rules)」分頁貼上下方規則並點「發布」：
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /rooms/{roomId}/{document=**} {
      allow read, write: if true;
    }
  }
}

步驟 2貼上 Firebase 金鑰並一鍵打包 index.html（約 1 分鐘）

在 Firebase 專案設定（齒輪）→ 您的應用程式 → 點「網頁 </>」註冊應用程式，複製 firebaseConfig 裡的大括號內容貼到下方：

步驟 3上傳至 GitHub 並開啟免費 Pages 網址（約 2 分鐘）

  1. 登入 GitHub → 點右上角 + → New repository → Repository name 輸入 health-coin-quiz → 確認為 Public → 按綠色 Create repository。
  2. 在新建專案頁點藍色連結 uploading an existing file，把剛才下載的 index.html（若要使用自訂音樂與音效，將下載好的 bgm.mp3 與 sfx.wav（或 sfx.mp3） 一起拖曳上傳到同一個資料夾），捲到底部點 Commit changes。
  3. 點上方分頁 Settings → 左側點 Pages → 在 Branch 下拉選單選 main、資料夾選 /(root) → 點 Save。
  4. 等待約 1 分鐘重新整理頁面，頂部就會出現 https://你的帳號.github.io/health-coin-quiz/，用電腦開這網址投影、手機掃 QR Code 就能百人同步開玩！
